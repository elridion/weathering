# Weathering

Valheim mod that lets player terrain edits outside player bases heal: dirt and cultivated paint fade,
height edits erode (diffusion of the offset field), each spot 3 in-game days after its last edit.
Stack, build, verification and git workflow are shared by all mods: see `../CLAUDE.md` and
`../.claude/rules/`. `docs/design.md` is the spec, `docs/plan.md` the task list.

## Where things are

- `src/WeatheringPlugin.cs` binds the config and applies the Harmony patches. Later files (stamp
  store, terrain patches, base index, healer, heal runner) are listed in `docs/plan.md`.
- `tools/make_icon.ps1` generates `package/icon.png`. `docs/` design notes. `hexium.json` Hexium
  listing metadata.
- The mod has no player-facing strings: no translations, no `AddLocalizations`.

## Invariants that must not break

- **Saved-world compatibility.** Persisted or networked identifiers: plugin GUID
  `elridion.weathering`, ZDO keys `weathering_stamps` (byte[]), `weathering_pending` (bool) and
  `weathering_last` (long, world time in whole seconds of the last heal pass), and config
  section/key names (renaming a key resets users' settings). It also reads Warden's
  `spawnward_radius` (float) and prefab `piece_spawnward`; those belong to Warden.
- **Removing the mod must leave a valid world.** Only ever write vanilla-valid `TerrainComp` data.
- **Docs follow code.** `package/README.md` keeps the config table in sync with
  `WeatheringPlugin.Awake`, and its lists of what heals and what never does with the heal rules.
