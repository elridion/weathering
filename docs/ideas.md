# Ideas for later

## Vegetation regrowth

Parked 2026-10-28. Trees were then added to v1 (see "Tree regrowth" in `design.md`); rocks and
ore stay parked.

- Trees: done in v1. A felled tree comes back as its vanilla sapling where its stump is gone.
- Rocks: mined boulders and stones reappear.
- Ore deposits (copper, tin, silver, ...): probably excluded, as Regenerative Terrain does by
  default, so mining stays a finite resource.
- Same rules as terrain: per-spot delay (3 in-game days), nothing inside player bases.
- Open: stumps (vanilla leaves a stump; regrow from it?), log piles left lying around, what a
  "spot" is for an object that was destroyed (no ZDO left, so the regrowth site must be recorded
  when it is destroyed).

Prior art: RustyMods' Regenerative Terrain (vegetation options: Exclude Ores, Exclusion list,
Growth Duration, Respawn Time); sighsorry's FreshWorld restores resources like copper and silver
on a schedule.
